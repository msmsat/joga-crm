# AURA demo: photo sources

The AURA demo data uses real editorial images hosted by Unsplash rather than
illustrations or AI artwork. The direct URLs are embedded in
`back/scripts/seed_aura_demo_studio.py` so the existing `photo_url` fields work
without a storage migration.

- Studio and hall imagery: [Unsplash yoga-studio collection](https://unsplash.com/s/photos/yoga-studio)
- Coach imagery: [Unsplash fitness-instructor collection](https://unsplash.com/s/photos/gym-instructor)
- License terms: [Unsplash License](https://unsplash.com/license)

For a public production launch, replace these demo images with photographs that
the studio owns or has specifically licensed for its brand. Do not use a demo
photo to imply that a real person teaches at the studio.
