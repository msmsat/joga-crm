# Velora CRM — Roadmap LAYOUT: каркас приложения (Sidebar / Navbar / DashboardLayout)

Каркас — единственная часть продукта, которую пользователь видит **на каждой
странице**. При этом он остался последним местом, где живут русские литералы в
JSX и три захардкоженные строки-заглушки («Studio Pro · Пилатес центр», «АМ»,
`admin@velora.studio`). Роадмап приводит каркас к тому же стандарту, что и
остальные разделы: строки из i18n, данные из глобального кэша, реактивность без
F5, hover-состояния на существующих токенах ДС.

**Задач мало и они однородные — весь объём укладывается в один эпик.**

**Действуют общие решения V3/V5 (на всё приложение):** TanStack Query как кэш
данных (без F5), единый UI-кит (`front/src/components/ui/`), токены ДС из
`App.css` (`--accent`, `--shadow`, `--radius-sm`), i18next по неймспейсам.

### Три конкретных дефекта

1. **Название студии в сайдбаре — литерал.** `Sidebar.tsx:56` рендерит
   `Studio Pro · Пилатес центр` независимо от того, чья это студия. Реальное
   название лежит в `Studio.name`, отдаётся работающим `GET /settings/general`
   и уже закэшировано под ключом `queryKeys.studioSettings` — просто никто его
   в каркасе не читает.
2. **Пилюля профиля — тоже литерал.** `Sidebar.tsx:165-166`: аватар `АМ`,
   email `admin@velora.studio`. Реальные данные — `GET /auth/me` (`UserMe`),
   ключ `queryKeys.me` уже заведён и используется Настройками.
   Hover при этом — `background: var(--bg)` (`App.css:901`), то есть
   `#FFFFFF → #FDFCFB`: разница в один процент яркости, элемент выглядит
   неинтерактивным.
3. **Неймспейс `menu` заведён, но пуст.** Файлы
   `front/src/locales/ru/menu.json` и `front/src/locales/en/menu.json`
   существуют, весят **0 байт** и не зарегистрированы в
   [i18n.ts](../../front/src/i18n.ts). Готовое место под ключи каркаса —
   заполняем его, новых неймспейсов не заводим.

### Скрытый баг реактивности

`i18n.ts:88` стартует с `lng: 'en'`. Язык студии (`Studio.language`)
применяется **только** в `onSuccess` мутации сохранения
([useGeneralSettings.ts:28-30](../../front/src/pages/dashboard/Settings/hooks/useGeneralSettings.ts)).
На обычном входе в приложение его не применяет никто — владелец студии с
`language: 'ru'` после логина видит английский интерфейс до тех пор, пока не
зайдёт в Настройки и не пересохранит язык. Чинится одним эффектом в каркасе
(эпик, задача 2).

## Общие решения роадмапа

1. **Ни строчки бэкенда, ни одной миграции.** Всё нужное уже отдаётся:
   `GET /settings/general` → `{ name, language, currency, … }` и
   `GET /auth/me` → `{ name, last_name, email, role }`. Новых полей, таблиц и
   Alembic-ревизий эпик не требует. Структура БД не меняется.
2. **Никакого нового глобального стейта.** В проекте уже есть источник правды —
   кэш TanStack Query (`queryKeys.studioSettings`, `queryKeys.me`). Заводить
   `AuthContext`/Zustand под два поля — оверинжиниринг: контекст пришлось бы
   синхронизировать с тем же кэшем вручную. Реактивность даёт сам Query:
   `setQueryData` в мутации Настроек → подписанные компоненты каркаса
   перерисовываются сами.
3. **Hover-эффекты — на существующих токенах, без новых зависимостей.**
   `transition` у `.user-pill` уже объявлен, палитра hover уже задана
   `.nav-item:hover` (`rgba(252,174,145,0.08)`), тени — `--shadow` /
   `--shadow-hover`. Ни framer-motion, ни нового CSS-слоя: правка одного
   правила в `App.css`. Tailwind-стек в каркас не тащим — файл на CSS Modules
   /глобальном CSS, смешивать подходы в одном файле запрещено §5 CLAUDE.md.
4. **i18n — существующий пустой неймспейс `menu`.** Ключи меню, заголовков
   разделов и подписей каркаса. Все резолвятся **внутри рендера** — модульные
   константы со строками (`ROUTE_META`) переводятся в карту ключей, иначе
   смена языка не перерисует шапку (та же ловушка, что разобрана в
   [EPIC_D1](../ROADMAP_DASHBOARD/EPIC_D1_LOCALIZATION.md)).
5. **Иерархия бренда фиксируется в типографике, а не в разметке.**
   `Velora CRM` остаётся логотипом (18px/800, точка-акцент). Название студии —
   подпись 11.5px/600 в `--text2`. Пропорция сохраняется в обеих темах, потому
   что обе строки берут цвета из токенов.
