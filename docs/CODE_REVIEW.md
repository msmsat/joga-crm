# Журнал код-ревью

По одной секции на каждый завершённый эпик. Ревью — обязательный шаг перед закрытием эпика
(см. [`ARCHITECTURE_RULES.md`](ARCHITECTURE_RULES.md) → «Завершение эпика»). Новые секции
дописываем **в конец**, старые не правим.

## Шаблон секции

```
## Epic: <название эпика>

**Дата:**

**Изменённые файлы:**

**Итог ревью:**

**Проблемы архитектуры:**

**Найденное дублирование:**

**Производительность:**

**Безопасность:**

**Добавленный техдолг:** (ссылки на записи в TECH_DEBT.md)

**Статус:** ✅ Approved | ⚠ Needs attention
```
