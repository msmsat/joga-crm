# Технический долг

Реестр замеченного, но намеренно **не** починенного в момент обнаружения (правило 3 из
[`ARCHITECTURE_RULES.md`](ARCHITECTURE_RULES.md)). Записи только дописываем — старые никогда
не удаляем; закрытые помечаем `✅ Закрыто <дата>` прямо в записи.

Долг, внесённый **текущим** эпиком, сюда не пишем — он чинится сразу.

## Формат записи

```
### <Короткое название>

- **Дата:** YYYY-MM-DD
- **Приоритет:** High | Medium | Low
- **Файлы:** путь:строка, путь:строка
- **Описание:** что не так и почему это долг
- **Рекомендуемый рефакторинг:** что сделать, когда дойдут руки
```
