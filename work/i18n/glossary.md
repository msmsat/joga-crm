# CRM terminology decisions

These are meanings, not literal word-for-word instructions. Choose each target
language's natural compact CRM equivalent and retain the distinction below.

| Source concept | Agreed UI meaning | Do not confuse with |
| --- | --- | --- |
| studio | the business using Velora CRM | a physical branch |
| client | a customer/visitor of that business | the CRM user or employee |
| staff member | a team member with CRM access | trainer/coach as a specific role |
| trainer | the person conducting a class | generic staff member |
| class | a scheduled session/lesson | a client's booking |
| booking | a client's reservation for a class or service | the class event itself |
| schedule | the calendar/timetable | an individual class |
| membership | a client package/pass of visits | the studio's Velora subscription |
| space | configurable business place: room, chair, cabinet, etc. | a branch |
| branch | a business location with its own address | a room/space inside it |
| service | a sellable service or offering | a scheduled class |
| invoice | a payment document | a financial account/cashbox |
| payment | money received or sent in one operation | an invoice or subscription |
| refund | money returned after a payment | cancellation alone |
| revenue | total income from sales in the reporting period | profit after costs |
| visit | attendance/check-in by a client | a booking |
| cancellation | a cancelled class or booking | a refund unless one occurred |
| waitlist | queue of clients waiting for an available place | a booking list |

Keep `Velora`, product-plan names, technical identifiers, URLs, API fields, and
currency codes unchanged unless the English source already supplies a localized
display string.
